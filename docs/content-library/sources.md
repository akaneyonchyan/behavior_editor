## 已记录的解释与冲突处理

以下是2026-10-17核对时的结论，不是实时库数量或完整现行工程表：

- 饥饿/饱腹满足度的数值方向需写清，不能因名称推断“越高越饿”。
- 伙伴脏污按专门系统规则作为保存值；不因叙事示例提到 Buff 就重复新增脏污 Buff。
- 品质按业务配置字段处理，不为下拉方便另建属性；库存、装备、占用等同理。
- 食物新鲜度、钓鱼等级及环境读取等须辨别计算/外部来源和可写性。编辑器当前尚未全面限制只读属性的“增/减”选择。
- 情绪分类、PAD推导结果与情绪 Buff 分开；旧情绪总入口不能替代全部分类。
- 手持物、食物等设计筛选类别保留引用兼容，不据此复制实际对象实例。
- 文档示例编号、参数不能冒充工程正式配置。编辑器英文标识不是引擎数值 ID。
- 行为表 provideGoals/requireGoals 与叙事文档 supportedGoals/preconditionGoals 不应视为已实现的同一格式；编辑器元数据也不等同于完整工程导出。
