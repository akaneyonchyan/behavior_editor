# 公共内容库说明

更新日期：2026-10-17。

公共库提供对象类型、具体对象名录、属性和 Buff 的定义及适用范围，供编辑器筛选候选；行为实例、具体数值和行为图不保存在公共库中。

| 维护任务 | 阅读入口 |
|---|---|
| 理解分类、字段和引用 | [使用规则与数据结构](rules.md) |
| 在飞书新增、修正、停用条目，排查同步 | [维护方式](maintenance.md) |
| 追溯规则依据、辨别待确认内容 | [来源与待核对事项](sources.md) |
| 修改编辑器/同步代码 | [开发与协作](../tool/development.md) |

当前唯一生产维护入口是团队指定的飞书多维表格。GitHub Actions 读取后发布静态 JSON，网页只读。实际表格入口由项目维护人提供；应用凭证及表 ID 存在仓库 Secrets，不在文档中填写值。

本目录只整理规则、来源指针和维护流程，不复制内部原始表格。本次文档整理未改飞书数据，亦未重新核验来源文档是否有新修订。需要改库时先打开当前原文和工程表核对。
