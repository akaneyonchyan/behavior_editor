# 产品说明

更新日期：2026-10-19。

## 定位

面向行为策划的可视化设计工具：用行为设计节点及连线观察行为全貌，填写规则与定性的数值期望，输出可继续编辑的 JSON。精确概率、系数、阈值平衡及工程配置转换属于后续环节。

团队共享同一个编辑器网址和只读公共库；每个人编辑自己的本地行为文件，通过团队自己的 Git 仓库同步。当前支持 GitHub 公开仓库共享行为文件，但没有多人共同编辑行为图；编辑仍在本地进行。

## 画布与节点

| 节点 | 设计内容 |
|---|---|
| 开始 | 蓝色唯一入口，展示行为准入数据；不可删除或复制，不出现在节点列表；无入线，单一后续出口 |
| 待机 | 待机说明及后续流程 |
| 判断 | 共同参与判断的来源、属性；各分支默认概率和属性影响 |
| 执行 | 表演描述与播放方式；分开的属性、Buff、产物输出 |
| 循环 | 按最大次数或目标满足情况判定，重复执行内部流程 |
| 结束 | 行为结束的设计说明 |

无节点选中或选中开始节点时，右侧显示行为准入数据。满足目标至少保留一条，填写来源、属性、增加/减少/改变；交互对象、消耗品和准入条件可为空。

判断分支默认概率为极高/高/中/低/极低。共享属性列表只选来源与属性，各分支继承后分别设影响方式；新增分支也继承。影响选项以当前界面为准，都是设计语言，不执行概率计算。

执行节点按行编号展示属性输出；Buff、产物分别展示，未配置时隐藏。表演播放方式为单次/计次/计时，工具不实际播放动画。

循环只负责次数或目标判定；准入和个性待机通过容器内部的判断、待机节点表达。旧版三阶段配置仅作为迁移兼容保留。

连线目前采用贝塞尔曲线、箭头和动态流光；旧避障实现保留在源码中，但不是画布当前使用方式。节点摘要可直接阅读，不必逐个选中。

## 自定义选项

通用下拉框允许填写不在候选中的文字，并加下划线。它用于表达待支持的规则、收集后续开发需求，不代表规则已经通过语义校验。不要把自定义文字自动当作新增公共库条目。

## 能力边界

支持导出 PNG：完整行为图或当前视口、1倍或2倍清晰度，保持深色背景与静态曲线箭头，去除编辑辅助元素。独立副本生成图片，不改变画布和文件状态。超大图片会提示调整导出选项。

- JSON 是编辑器设计文档，不是可直接导入游戏的工程配置。
- 导入校验负责结构和部分引用约束；不保证全部玩法规则、只读属性写入、目标可达性正确。
- 不运行行为模拟、实际属性结算或 Buff 计时。
- 公共库更新有发布延迟；页面刷新只读取已发布版本。
- 自动缓存用于恢复，不代替手动保存和团队 Git 提交。


## 结束表演（2026-10-19修正）

结束只有一种节点、一个工具栏入口。每个实例配置一套表演和播放方式（单次／计次／计时），计次／计时可填写文字期望。结束节点用于行为内明确设计的收尾，不设结束类型字段。通用意外中断和监听跳出交给行为外规则，默认模板只有一个正常结束节点。

已有图的表演、名称、连线不变；旧 endReason 仅作为兼容数据保留，不展示、不参与规则，新建节点不生成该字段。旧 successAnimation/failAnimation 仍提供“拆分为两个结束节点”入口：按旧表演分配入线，保留原配置，支持撤销。拆分后的两个节点类型完全相同。正式文件仅手动保存后写回。

规则来源：[行为通用规则](https://xd.feishu.cn/wiki/HpD0wJZg7icrpKkXdkDcAjHDnBg)。结束类型不是编辑器规则，这是2026-10-19用户明确修正的产品约束。相关回归见 tests/endings.cjs、tests/endings.spec.cjs、tests/end-node.spec.cjs。

## 占用资源与行为结束（2026-10-19）

执行节点可声明“占用资源”（旧文件中的位移声明兼容保留）：对象来源＋属性名，支持公共库选择和自定义下划线输入。含义是该节点执行时产生、由本行为持有至结束的占用；仅移动或普通属性增减不能推断为占用。

结束节点的“释放资源（自动）”引用从开始可达且能通向本节点的前序声明，展示对象、属性、来源节点；修改、删除、断线、撤销及公共库改名均自动反映。各分支引用取并集，不意味着每次全部占用；设计语义是只释放本次实际产生、仍由本行为持有的资源。编辑器不模拟运行时，不凭对象类型猜测具体实例或释放顺序；同类型的不同占用由来源节点与声明ID分别追踪。

实现：occupiedResources=[{id,source,attribute}] 存在来源节点，utils/occupiedResources.js 按有效边遍历，排除禁用稍息路径、孤立节点和结束节点后的边。派生引用只在展示时计算，不复制写入结束节点。旧 releaseResources 原文放在核对区，需整理为前序声明；旧 targetCondition 仅兼容保留、不展示、不执行。

结束节点不再配置或展示目标判定。目标是否达成及后续调度属于行为之外的目标策略流程；开始节点中行为准入数据的满足目标、循环中的循环判定仍保留。回归见 occupied-resources.cjs 与 occupied-resources.spec.cjs。

## 需求整理

顶部“需求清单”将当前行为的未匹配属性、对象、Buff、自定义规则和待核对表演分组汇总，提供使用位置与 Markdown 导出，帮助策划整理版本需求。检查以当前公共库快照及编辑器规则选项为依据，不承诺判断游戏工程支持情况。表演未接资产库，全部按待核对资产处理。

## 在线行为共享（2026-10-20）

左侧文件区新增本地／在线页签。在线从公开仓库 behaviors 目录读取，只读预览；下载到保存目录后编辑。选择本地 JSON 上传时创建分支与 PR，审核合并后刷新目录查看。支持同名替换、版本冲突提示与本地覆盖保护。详见[在线文件说明](online-files.md)。本地自动缓存不上传。


## 跳出行为与旧位移迁移（2026-10-20）

判断分支、执行节点后续、循环各已启用出口，都可选择“连接节点”或“跳出行为”。后者显示节点色的“↗ 跳出行为”标记，可填可选说明，不配置外部流程，也不隐含结束表演、目标判定或资源释放。需要失败表演时，先连执行节点，再跳出。监听随时触发的通用中断无需逐节点配置。

切换为跳出会移除该出口的连线，保留原目标节点及其表演，支持撤销；切回连接节点时处于未连接状态。循环步骤关闭时隐藏对应标记，重新启用恢复。在线只读预览、PNG、保存恢复及复制排序均保留标记。通用跳出的资源清理由行为外规则负责；正常结束仅展示可追溯的占用，无占用时隐藏。

新建不再提供位移节点，默认模板不含位移和中断结束。旧文件不自动改写：选中旧位移，点击“移除旧位移并接续”，仅在正常出口唯一且接续不会生成自身循环时执行，前序出口身份保持不变。原位移数据及涉及连线存入 behavior.legacyMovement，支持撤销；原结束节点不会自动删除。请核对原占用与自定义说明，外部占用不自动搬到执行节点。旧中断连线可逐条切换为跳出，不按节点名猜测。

缓存模板有独立版本；回退到旧缓存模板时采用新版内置模板。现有正式文件和编辑草稿继续恢复，不清空缓存，不批量迁移线上文件。examples/eat-snack.json 保留为旧格式兼容示例；新格式示例见 examples/external-exits.json。


## 在线需求汇总（2026-10-20）

切到“在线”页签后，顶部“需求清单”会读取全部已发布在线行为文件，无需先选文件，也不受左侧文件搜索过滤影响。按属性、对象、Buff、表演四个页签汇总；相同字段、内容、原因及对象上下文合并为一行，列出涉及文件及行为名称，可展开节点使用位置。不同对象上下文不强行合并。表演仍属于待核对资产，不代表已确认缺失。

点击清单内文件名，在主画布打开对应已读取版本，只读查看；本地草稿和撤销历史不被替换。“搜索需求清单”支持按行为文件名搜索。“导出完整清单”导出四个页签，包含文件来源、在线快照及公共库时间；不受当前搜索过滤影响。

打开窗口时读取在线目录，可点击“重新读取在线文件”更新；仅涵盖已发布版本，不含未合并 PR，存在发布延迟。读取失败逐文件提示，已成功读取部分仍可查看和导出，导出明确注明清单不完整及失败文件。全部读取失败、目录失败或公共库未就绪时不允许导出成功清单。关闭窗口取消剩余请求。公共库更新会重新核对本次已经读取的文件。

本地页签仍只汇总当前正在编辑的行为。在线扫描不需要 GitHub Token、不写仓库、不保存或修改本地行为。


## 父子结构视图与循环容器（2026-10-20 修订）

循环自身只配置执行条件：按最大次数，或按目标满足情况。每轮执行前先判定，达到次数／目标满足后离开，否则执行内部节点。最大次数允许填写设计期望，不做数值模拟。目标模式未单独配置条件时引用行为准入数据中的满足目标；旧图已有目标规则可在目标条件详情中维护。

结构视图用循环容器本身展示条件，顶部可直接切换条件类型、填写次数，右侧面板同步；在线为只读摘要。框内不再重复放循环节点。内部顺序从左向右，判断分支上下排列，共同后续只显示一份，支持嵌套及折叠。准入检查由内部判断节点表达，个性待机由内部待机节点表达，不再是循环的开关或固有阶段。

内部节点回到所属循环的线在结构视图隐藏，本轮结束后自动重新判定。底层仍兼容返回连线以保留已有图的结构与占用追溯；新图确认范围时，为没有后续且未标记跳出的执行／待机末尾补齐返回关系，无需手动画回线。判断分支的空出口不推定为完成一轮，须明确设计。原连线视图保留实际关系以供复杂编辑。

旧文件不自动改写。选择旧循环，点击“拆分为循环容器与内部节点”：原准入与稍息拆成内部判断，保留原分支去向、属性及自定义规则，已有待机节点复用，无待机时创建待机节点。原数据及连线完整归档，支持一次撤销。迁移出的条件文字不擅自换算为数值概率，使用自定义文字标记供继续核对；旧版兼容配置在迁移前可展开检查。存在不明确入口或缺失循环返回时会阻止转换，先核对原图。迁移后仍需手动保存正式文件。

顶部视图页签顺序为“连线视图／结构视图”，默认仍为结构视图，保留用户原先选择。结构视图支持节点属性编辑、容器整体移动、折叠和重排；复杂连线及单节点自由移动在连线视图进行。容器不是新增行为节点，节点类型和属性／Buff／产物配置不变。

完整 PNG 通过独立展开副本生成，包含容器条件，不改变当前折叠或保存状态；可见区域按当前视口裁切。执行节点的普通出口固定在节点右侧居中，没有空分支占位，跳出行为仍显示原标记。
