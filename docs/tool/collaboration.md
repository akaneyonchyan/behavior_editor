# 同一 GitLab 行为文件的多人协作

2026-10-28：实现位于 feature/collaborative-behaviors，需配置独立协作服务后发布。不能把本地测试通过理解为生产已启用。

## 使用

有编辑权限时，点击在线行为文件直接在原主界面加入协作，不打开弹窗或二级页面；保留左侧文件列表及节点栏、中间画布和右侧节点表单；点击节点获得编辑权后填写。退出协作回到预览后，可通过右侧「进入在线编辑」重新加入。未验证或无写权限时保留只读预览并说明原因；原始 JSON 默认折叠在「查看原始 JSON」中。

个人权限卡片右上角可随时展开或收起。验证成功（含自动恢复本机凭据）后默认收起输入区，仅保留标题与展开按钮；展开后可重新验证或清除凭据。清除后重新展开输入区，说明及错误信息也随输入区一并收起。

切换到「在线」时会重新验证个人 GitLab 权限。首次输入自己的个人 API Token，点击「验证」，再点击文件直接进入协作编辑。按 [Token 创建指引](https://xd.feishu.cn/wiki/OIECwWxUviBhIZkqvH8cX2eqn0g) 选择 api、write_repository，并确保本人对 petpals/shared/design_behavior_editor 的 master 分支有写权限。没有写权限时，共同编辑入口不可用，保留现有 SSO 允许的只读浏览。

「记住此浏览器」将凭据加密保存到当前浏览器 IndexedDB，按站点登录身份分隔，刷新后自动读取并重新验证；换设备需重新输入。「清除本机凭据」移除本机记录和当前页面凭据，既有短期协作票据最多 15 秒失效，不撤销 GitLab 上的 Token。本地加密不能抵御同源恶意脚本。

浏览器直接读取和保存 GitLab，需要公司网络，并在浏览器询问时允许本地网络访问。Token 仅发往 GitLab 和当前站点 Worker（权限与提交结果复核），不传给独立协作服务器或写入行为文件。未提供个人 Token 时仍可使用原有 SSO 只读预览。

- 点击节点取得独占编辑权，再填写右侧配置或拖动。节点显示占用人的姓名；别人仍可查看画布，但不能同时编辑该节点。点击空白释放。
- 行为准入数据由开始节点的锁保护。涉及多个节点的连线、删除、循环归属调整会原子检查所有受影响节点；任一节点被别人占用就拒绝整个操作。
- 顶部显示在线人员，画布显示各人的光标和节点姓名。点击人员标签定位到其节点或光标；坐标使用图坐标，可跨缩放和平移。
- 不同节点的修改合并到同一份共享草稿。已同步草稿存于服务端，刷新或服务正常重启后可继续。
- 点击顶部原「保存」按钮或 Ctrl/Cmd+S 保存整个共享草稿到 master 中的原文件。提交记录包含保存人与参与人；通过点击保存者本人的 API Token 写入，保存前重新验证该账号的分支权限。
- 保存遇到仓库外部更新会阻止覆盖。下载当前副本，在 GitLab 整合；管理员备份并归档冲突房间后，所有成员重新加入最新文件。不提供强制覆盖。
- 保存时暂时冻结共享稿版本，浏览器直写后由 Worker 复核成功才显示已保存。保存中断可重新加入并再次保存以核对结果；结果未核实前不会自动恢复编辑，也不会重复覆盖外部更新。

## 断线和恢复

连接连续 5 秒未确认会停用编辑；服务端节点租约 15 秒，通过请求续期。过期会释放锁，旧会话不能恢复写入，必须重新加入。服务重启使旧会话全部失效，但保留已确认的草稿。

失败不会把乐观修改当作已同步：界面暂停，允许下载当前副本。未同步修改尽力写入每个页面独立的浏览器恢复记录；存储不可用或配额不足时仍须下载副本。重新打开同一文件会展示现有恢复副本。恢复副本不会自动写回共享文档。

左侧原节点栏支持点击添加或拖入协作画布；顶部「另存为」下载当前共享稿。切换文件、本地页签或退出协作时，未同步修改会提示确认，已同步共享稿留在服务端。

本地文档的文件句柄、撤销历史与自动缓存仍使用原状态；协作编辑使用单独 store。退出协作后原本地草稿不变。

## 当前范围

支持节点配置、新增、删除、拖动及连线；协作画布使用连线视图。工程视图继续在原只读预览/本地编辑中使用。协作暂不提供全图撤销、重做或结构画布编辑，以免整图历史覆盖别人的修改。

当前采用约 350 毫秒的增量轮询，有变化才传图内容，空闲时只同步人员与光标；并非 WebSocket。网络与 GitLab 保存时延可能使显示延后。共享草稿与 GitLab 正式文件是两层状态，行为预览读取已手动保存到 GitLab 的版本。

## 实现与验证

- shared/collaboration.mjs：节点/连线实体级比较与合并，保留不相关修改。
- server/collaboration-rooms.mjs：单文档队列、节点租约、会话身份、幂等操作与保存。
- server/collaboration-service.mjs：单实例权威服务、写盘确认、GitLab 文件版本 CAS。
- server/collaboration-proxy.mjs：Worker SSO 身份转发、同源校验与服务凭据。
- src/store/collaborationClient.js：隔离编辑状态、在途修改保留、断线暂停。

执行 npm run test:collaboration、npm run build:sites-worker、npm run test:collaboration:browser。双浏览器测试使用两个隔离身份与真实本地协作服务，GitLab 用测试仓库适配器，绝不改生产行为文件。

部署条件见 [协作服务部署](../../deploy/collaboration.md)。
## 2026-10-30 节点选择与编辑锁

画布的选中事件（包括键盘选中）与点击事件统一进入协作选择流程。右侧面板立即展示选中节点，申请锁期间显示“正在获取此节点编辑权”，表单保持不可编辑。只有服务端确认自己持有锁时才开放表单并显示“我正在编辑”。选中其他人占用的节点可查看属性，但不能修改；拒绝抢锁不会中断同步。快速切换节点时，旧锁请求的回执不得把面板切回旧节点；空白处释放锁。
