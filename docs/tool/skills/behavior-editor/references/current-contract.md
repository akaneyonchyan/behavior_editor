## 节点与文件

- 页面使用“行为准入数据”“执行节点”“工程视图”；数据兼容保留 behavior、result、structure 等实际键。
- 开始节点蓝色且唯一，不可删除／复制；图外位移、寻路失败、监听中断不重复画入行为。新稿没有 move，源码中兼容定义的存在不代表仍提供给设计者。
- 判断的 judgeAttributes 声明参与属性；各分支的 weightFactors 关联共享项。默认概率为极高／高／中／低／极低。影响类型为数值高／数值低／具体值；影响规则为概率越高／概率越低／允许选中／排除选中／不影响。非标准输入保留并标下划线。
- 执行的属性、Buff、产物分栏，空栏隐藏；有输出时逐条显示。执行与结束表演均支持单次／计次／计时。结束只有一种类型，目标策略判定在行为外；释放资源按实际可达的前序占用来源引用，不猜对象。
- loopVersion:3 使用 loopConditions 有序 OR 结束条件，默认目标项在前、次数项在后；每轮先判定，满足任一项即结束。一条目标项内 rules 为全部满足；不填 rules 时界面提示引用行为准入目标。
- 循环设置只在右侧编辑。已移除“补充条件说明”输入框；新稿规则填进 rules 的参数和规则描述，不再填 condition 来代替参数。历史 condition 仍保留在文件和摘要中，不因 UI 删除而批量清空或擅自解释旧文字。
- 工程视图顺序节点横向展开，同级分支纵向排列；局部回路只在布局计算中排除回返边，不删除真实连线。保存的手动坐标优先，点击“重新排布”更新自动位置。
- 循环外连线接容器边界；内部左侧开始标记，右侧只有 ↻ 图标。真实继续循环的边指向所属循环节点，视图映射到右侧标记，不将标记当独立业务节点导出。空出口不自动补线；嵌套、离开与返回按实际边界处理。
- 拖入、拖出或跨容器移动按新归属更新，清理旧跨范围连线，可撤销。节点、连线可选择删除；空容器不锁定其他节点。externalExits 与同一出口内部连线互斥，跳出不隐含结束表演或资源释放。

## 公共库引用

按实时快照解析对象大类 source=object:<对象ID>、对象子类 objectName=item:<名录ID>、判断项 attribute=<属性ID> 或 buff:<Buff ID>。名录 ID 本身含类型/条目标识，不手拼示例 ID。

伙伴执行者来自伙伴名录的“行为伙伴”，互动者按设计选任意伙伴或对应伙伴条目；不新造“执行伙伴／交互伙伴”对象大类。个性标签可分别是属性，不能只查“个性”总项；装备槽按当前库分项选，不从旧手持物标识猜映射。

Buff 作为对象时，其子类名录复用 Buff 基础表；object:buff + item:buff/... 表示引用 Buff 本身。对装备物施加 Buff 则应选装备物及 buff:<ID>，不能因为 Buff 归在 Buff 对象名录，就把效果目标改成 Buff 对象。

属性 kind 只允许“数值／枚举”，布尔按枚举。发布校验包括停用条目；kind 合法不等于语义无误。停用条目不用于新设计；历史引用保留，迁移须核对对象和意图，不按同名或近义词直接替换。

- 在线文件读取 Pages 的 data/behaviors/index.json；公开浏览不需 Token。上传创建分支与 PR，合并发布后才进入在线目录。刷新不会触发 GitHub 发布，也不会替换已经打开的固定版本。
- 拉不到新文件时，核对 PR 是否合并、main/behaviors 是否含文件、目标提交发布是否成功，再比较已发布目录的文件名与 SHA、搜索过滤和实际刷新响应。不能直接归咎 Token 或声称刷新按钮损坏。
- 本地需求清单只检查当前图；在线清单扫描所有已发布文件，不受当前预览／目录搜索限制。按属性、对象、Buff、表演分页，按字段和对象上下文合并，保留各文件及位置。
- 在线引用默认收起显示“N 个文件引用”，展开后一文件一行；文件名可只读打开，使用位置另展开，行为名在悬停提示中。搜索与导出不受折叠影响；部分读取失败必须报告不完整。
- 表演尚无资产目录，“待核对资产”不是已证实缺失；自定义规则也不自动成为待新增属性。
- PNG 保存弹窗优先本地保存目录；成功提示在下方 document-message 消息区，不插入按钮区域。保持工具栏几何尺寸稳定；已有错误不能因导出成功被清掉。导出不保存 JSON。
