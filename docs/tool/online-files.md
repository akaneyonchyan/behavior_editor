# 在线行为文件

## 单图只读分享（2026-11-03）

打开一张在线行为图后，点击顶部“复制只读链接”。接收者打开链接会直接进入该图的只读页面，不显示文件列表、编辑工具或协作入口；保留平移、缩放、连线／工程视图、循环展开及节点配置查看。复制被浏览器拦截时，可从出现的只读输入框手动复制。

链接按文件名读取在线最新已保存版本，不包含本地文件或未保存的协作草稿，也不上传当前画布。已打开页面不会自动替换图，刷新页面可读取最新版本。文件删除或改名后旧链接会提示重新分享；网络读取失败可重试。访问沿用原站点登录与网络权限，链接不含 Token，也不授予额外权限。

链接使用 view=readonly 与 file 查询参数定位文件，文件名自动进行 URL 编码。只读页面不启动本地文件持久化，不加入协作房间，不提供保存操作。

只读链接默认只展示标题与画板，始终不显示左侧行为节点和行为图文件库。JSON 配置默认收起；点击顶部“JSON 详情”打开只读浮窗，再点画板节点可切换查看内容。浮窗可通过“收起”、顶部按钮或 Esc 关闭，开关不挤压画板、不改变图位置，选择节点不会自动弹出浮窗。

手机宽度下 JSON 浮窗位于画板底部，默认仍收起；隐藏小地图，缩放与视图按钮使用至少 40 像素高的触屏区域。支持单指平移、双指缩放及点击节点查看配置。手机模拟回归：PW_CHANNEL=chrome、VITE_ONLINE_PROVIDER=gitlab-live 下运行 npx playwright test tests/readonly-mobile.spec.cjs；覆盖 320、390、430 像素宽度。

## 查看与本地编辑

左侧「行为图文件」标题下提供平直的「本地／在线」页签，选中项使用底色和下划线区分。在线目录读取公开仓库 akaneyonchyan/behavior_editor 的 main 分支、behaviors/ 目录，只显示本层 JSON 文件。首次为空是正常的，不会自动上传本机现有行为。

点击文件直接在主画布中只读加载，可平移、缩放并查看节点原始配置，不再弹出预览窗口。在线模式停用节点添加、保存、撤销和重做；切回本地页签即恢复原本地草稿。开始节点、循环出口和结束节点释放占用均来自该线上图；不会加载进本地编辑状态、覆盖本地草稿或成为自动缓存。预览中的删除、拖动节点、连线及编辑快捷键不可修改图。

先通过顶部「保存目录」选择本地文件夹，再点击顶部「另存为」。写入原始 JSON 后按现有文件打开流程切换；若不愿切换当前未保存内容，可取消切换，文件已下载到目录。下载前会确认本地同名覆盖；正在编辑且未保存的同名文件禁止覆盖。浏览器需支持目录访问（Chrome／Edge、HTTPS）。本地编辑仍需手动保存正式文件。

在线目录和行为 JSON 随 GitHub Pages 发布，浏览、预览、下载完全匿名，不调用 GitHub API，不发送 Token。合并后等待 Pages 发布成功，再点击「刷新」读取已发布目录；正在预览的是固定版本，不会悄悄替换。只有准备上传、创建分支和 PR 时使用个人 Token。

## 上传与授权

1. 在本地完成编辑并手动保存。
2. 打开「在线 → 上传授权」，填写自己的 GitHub Token。Token 只在当前页内存保存，刷新或清除授权后失效，不写 localStorage、sessionStorage、JSON 或仓库。
3. 点击「上传文件」，可选择 1–20 个行为 JSON，单个最多 2 MB、合计最多 10 MB。
4. 确认“新增／替换同名文件”清单及公开范围，再点击「创建分支并提交审核」。
5. 打开返回的 PR 链接，审核文件差异后由有权限者合并。提交 PR 不等于发布到在线目录。

上传者的 GitHub 账号必须有本仓库写入权限，仓库所有者可在仓库 Settings → Collaborators 中添加团队成员。Token 不能赋予账号本来没有的权限，也不要共用仓库所有者的 Token。

若账号允许为该仓库创建 fine-grained Token，选择仅此仓库，授予 Contents 和 Pull requests 的 Read and write；Metadata 保留默认读取权限。GitHub 对外部协作者的 fine-grained Token 支持存在限制，若无法选择此仓库，可使用有期限的 classic Token，公开仓库使用 public_repo 范围（账号仍需协作者权限）。只把 Token 填入编辑器密码输入框，不发到聊天或 PR。

参考：[创建个人访问令牌](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)、[细粒度权限](https://docs.github.com/en/rest/authentication/permissions-required-for-fine-grained-personal-access-tokens)。

## 覆盖、冲突与恢复

上传是 Git 分支加 PR，不直接覆盖 main。文件名决定新增或替换；不支持仅大小写不同的同名文件。上传前再次核对所涉及文件的 blob SHA；若相对确认清单已有变化则停止，要求重新核对。

通过本页面下载时，浏览器会记住文件名对应的公开版本 SHA。之后上传若发现线上已更新，会要求先下载最新版本并整合修改，或在 GitHub 手动处理分支冲突。此记录不包含 Token 或行为内容；换浏览器、清除存储、从其他途径拿到文件时无法知道原始编辑基线，因此首次上传仍必须人工审阅替换差异。

上传准备期间 main 其他文件的更新可保留到新分支。分支创建后 main 再变化由 GitHub PR 显示差异和可能的合并冲突；编辑器不尝试对行为 JSON 自动做语义合并。请勿把“Git 无文本冲突”等同于“行为设计没有冲突”。

网络或权限错误可能发生在分支已创建但 PR 未成功的阶段。页面会提供分支对比链接，先检查是否已有提交或 PR，再继续创建 PR，避免反复上传。不要在上传处理中刷新页面。

## 审核与校验

Validate shared behaviors 工作流验证 behaviors 目录所有 JSON，拒绝非法格式、路径、文件名和仅大小写不同的重名。它不读取飞书 Secrets，也不部署页面。发布工作流也先验证共享行为文件。

校验通过不代表行为玩法正确，审核者仍需检查文件内容。此功能不自动修改仓库保护规则；如需强制“至少一人审核且校验通过才能合并”，仓库管理员应设置 main 的 Ruleset/Branch protection。当前页面不提供直接合并按钮，审核在 GitHub 完成。

所有上传内容与 Git 历史公开。目录仅存行为文件，不放密钥、公共库快照或未经允许公开的设计资料。

本地／在线共用固定三栏布局与顶部工具栏。在线右侧保留只读配置面板，节点与编辑按钮留在原位但不可写入；选择节点不会改变栏宽。


## 在线需求汇总（2026-10-20）

切到“在线”页签后，顶部“需求清单”会读取全部已发布在线行为文件，无需先选文件，也不受左侧文件搜索过滤影响。按属性、对象、Buff、表演四个页签汇总；相同字段、内容、原因及对象上下文合并为一行，列出涉及文件及行为名称，可展开节点使用位置。不同对象上下文不强行合并。表演仍属于待核对资产，不代表已确认缺失。

点击清单内文件名，在主画布打开对应已读取版本，只读查看；本地草稿和撤销历史不被替换。“搜索需求清单”支持按行为文件名搜索。“导出完整清单”导出四个页签，包含文件来源、在线快照及公共库时间；不受当前搜索过滤影响。

打开窗口时读取在线目录，可点击“重新读取在线文件”更新；仅涵盖已发布版本，不含未合并 PR，存在发布延迟。读取失败逐文件提示，已成功读取部分仍可查看和导出，导出明确注明清单不完整及失败文件。全部读取失败、目录失败或公共库未就绪时不允许导出成功清单。关闭窗口取消剩余请求。公共库更新会重新核对本次已经读取的文件。

本地页签仍只汇总当前正在编辑的行为。在线扫描不需要 GitHub Token、不写仓库、不保存或修改本地行为。
