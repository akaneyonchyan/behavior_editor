# 行为预览场景

2026-10-23。使用原 GitHub 仓库，由 Pages 工作流发布到 https://akaneyonchyan.github.io/behavior_editor/ 。进入页面后点击标题旁的“行为预览”；也可访问 ?view=preview 。不涉及 GitLab 或云服务器部署。

## 本地运行

需要 Node.js 22+、Chrome/Edge WebGL。首次 npm ci，随后 npm run dev:preview，打开 http://localhost:5193/?view=preview 。脚本下载已发布的公共库及在线行为快照，校验后保存在被 Git 忽略的 public/data。网页刷新读取本地镜像，获取线上更新需重新运行启动脚本。已有快照可设置 VITE_LIBRARY_MODE=published 后运行 npm run dev -- --port 5193 --strictPort。

## 使用

工作区切换入口位于工具栏左侧：“PPS 行为编辑器｜行为预览”，与标题及操作同一行，不额外占据顶部一栏。

默认“行为模拟（数值表驱动）”，选择1～7天后开始；六名伙伴根据当前属性独立选目标、准备工具、执行真实在线图，结束后继续评分。单行为调试使用同一补值，只运行选定图。准入仍按原图，例如满精力不能睡觉，可在开始前调低精力测试。

- 左侧开关控制伙伴参与。关闭后中断、释放占用、归还工具；重新启用保留属性，从当前时间调度。点击伙伴查看其状态和路径。
- 开始/暂停控制时钟，重置恢复运行前场景。1×约每真实秒推进1游戏分钟，实际受设备性能影响。
- 右侧目标页显示当前在线图、数值依据、目标得分、可行性与完成次数；配置页显示原表和推导映射，记录页显示真实节点及分支结果。
- 场景/图分隔条支持拖动、方向键微调、Home复原。行为图默认居中全显，滚轮缩放、左键平移；支持100%、适应全图、定位当前节点。
- 地图固定正交，滚轮缩放、左键拖拽平移；触屏单指平移、双指缩放。布局含外围沙滩、林间采集、物资小站、生活庭院、中部花园、手作工坊及滨水码头。直线移动只是示意，尚未实现障碍导航。
- Buff只显示正层数。角色头顶节点与侧栏动作原文表示当前表演，模型仍为占位资产。

## 在线图与数值表

在线图决定准入、节点顺序、判断、循环、Buff、产物和结束。数值表补足消耗、恢复速率、耗时与目标权重。所有补值仅影响运行副本，不修改原始图、公共库和工作簿。界面没有单独的数值模拟入口。

来源：《伙伴行为选择模拟V3.2_轻量版.xlsx》。提取值和单元格出处在 src/preview/balance-data.json。同布局重新导入：python scripts/import-preview-balance.py "工作簿绝对路径"，需要 openpyxl。

| 项目 | 规则 |
|---|---|
| 目标权重 | 精力90、饱腹90、社交100、娱乐200；家园10000对应固定100分 |
| 需求得分 | exp((100-floor(当前值))/10)×权重/100，再乘日程倍率；最高可行分优先，同分按表顺序 |
| 睡眠日程 | 00～05时×100，05～06时×2，23～24时×4 |
| 用餐日程 | 06～08、12～14、18～20时×20；进食借用正餐数值，其余小吃 |
| 睡觉 | 睡眠节点420分钟，精力每分钟恢复99/420；每小时饱腹−6、社交−3、娱乐−6 |
| 坐椅休息 | 类比打盹：5分钟恢复精力10 |
| 进食 | 小吃5分钟饱腹+10；正餐30分钟+78，分配到实际进食节点；耗尽或变质不恢复 |
| 重体力 | 伐木/钓鱼每小时精力−12、饱腹−18、社交−3、娱乐−6 |
| 采集 | 伐木5分钟/次，木材2；钓鱼参考5分钟/轮、娱乐+2，成功肉2，空钩0 |

| 维护推导 | 清洗/打扫/维修类比日常或轻工作；有效节点每分钟清洁/耐久+2，工具耐久−0.2 |

需求连续按实际时间结算，恢复封顶100后扣消耗、下限0，等待/准备也消耗。节点不再重复固定加减10。图中明确计时优先，缺失才补值；恢复期望按本次初值加样本恢复量、上限100推导，明确数字比较保留。

原图概率仍使用定性映射极高9、高6、中3、低2、极低1，属性归一调整；这不是原表目标评分。循环仍有序OR先判断后执行，不补空线、不强制成功。真实分支、循环和跳出影响总时长，因此不承诺逐分钟复现工作簿轨迹。

## 准备、共享场景与边界

六名伙伴各自解释图并串行提交到共享世界。目标评分前检查绑定资源的预约，已被预约的行为不参加本轮竞争，其他可行目标照常选择；执行前再次检查冲突，每1分钟复查，连续3次后按失败冷却配置重选。空地/天气等环境上下文不独占，具体家具、工具和交互点仍需预约。全局时间、清洁与Buff到期只推进一次。每个行为及准备步骤结束重新竞争目标，保留实际属性与产物。食物吃完时清空食物装备槽，避免阻挡睡眠准入。

拿还鱼竿、扳手、抹布等缺少在线图的步骤使用标注的2分钟预览服务，不假称已有稿件。公共库停用工具用独立占位，不启用原条目。家园目前映射已有采集、清洗、打扫、维修，标明替代；缺少建造/家具在线图，不能完整复现原表建造经济。社交得分可查看，但按用户要求不调度双人行为，自主候选排除炫耀。

18份图都有补值映射；晕倒、摔倒、大笑、解卡需实际触发，不保证同一天全部出现。鱼饵沿用12分钟有效制作，榕树产量条件采用显式预览修正，均不回写原稿。状态/Buff继续按公共库定义及图内输出工作，含独立层、来源、到期撤销与PAD。未映射规则阻止执行并提示具体原因；手动适配只影响运行副本。

Buff 生命周期（2026-10-23）：依据用户最新要求，预览不再支持永久 Buff。[状态与 Buff 设计文档](https://xd.feishu.cn/wiki/QTKvwrzEgi9kAYkNOxBcFzS3nTh)第3.3、3.8节仍含永久选项，与本次要求冲突时以本次要求为准；未修改原文或公共库。文档示例 buff_10001 / buff_10003 为600游戏秒，既有疼痛180秒、晕眩360秒及其他已配预览时长保留；其余未给时长的项暂用600游戏秒，并在侧栏标注预览暂定。这些数值不是正式配置。每次获得独立计时，新增层不刷新旧层；鱼饵容量暂按1层，使用时仍可提前消耗。

自主模式、准备服务和单行为测试均使用游戏时钟到期撤销；暂停不走时，单步推进当前节点耗时。节点完成次数与持有关系解除可提前移除，但仍有有限时长上限；只计获得之后的完成事件，不重复计数。旧运行层缺少时长时按原获得时间补期限，不因刷新续期。到期重新计算现存层的属性修正及PAD，不倒扣基础属性；物品卡住、装备归属等真实关系不会随 Buff 到期自动解除。

## 开发与验证

网站根地址默认打开行为预览；顶部“PPS 行为编辑器”可切换到设计界面。需要直接进入设计界面时使用 `?view=editor`，`?view=preview` 仍可直接进入预览。

### 单行为测试与等待原因（2026-10-23）

单行为调试默认开启“自动准备准入状态”：在隔离副本中按当前图的准入设置属性、Buff、装备、天气和可用对象；维修/打扫目标设为30，解卡建立实际树与斧头关系。之后依然执行真实准入检查，不绕过判断、不保证所有随机分支成功。右侧可展开本次准备清单，重置返回原初值；关闭开关可测试准入失败。源码为 singleScenario.mjs，自主调度不会调用它，未支持的规则仍阻止运行。

节点说明卡片先显示当前实际行为名，再显示“当前执行节点”；等待时显示“暂无执行行为”，不沿用上一行为名。没有可行目标时，候选列表显示本轮全部排除原因和冷却，避免显示过期候选。

修复前默认六伙伴、满属性、种子42的一天样本中，每名伙伴约260～483游戏分钟处于等待（每分钟采样，含短暂行为间调度，不是连续最长等待）。设计/场景原因包括精力低于80才能休息、夜间晴天无踩水行为、维护对象尚无需维护、工具/点位数量有限且社交关闭。实现原因包括整片空地被独占、评分后才发现预约冲突、吃完未清空食物槽。前三处已分别修正；仍不通过自动生成工具、刷新产量或伪造社交行为消除所有等待。此样本仅用于定位，不代表正式游戏平衡结论。

rhythm.mjs负责数值映射与连续结算；rhythmScheduler.mjs负责评分与准备调度；onlineColony.mjs负责多人共享世界；runtime.mjs解释真实图；RhythmPanel.jsx显示来源。balance.mjs和colony.mjs仅保留为内部计算测试基准，不被预览界面使用。

执行 npm test、npm run build。浏览器设置 PW_CHANNEL=msedge 后执行 npx playwright test 'preview-.*spec.cjs'。preview-rhythm.mjs验证真实图耗时、需求速率、权重、准备、避免重复结算及六伙伴全天执行。内部原表10080分钟指纹只证明数值基准，不代表真实图轨迹逐分钟相同。

## 场景设计与状态可视化（2026-10-23）

布局覆盖林间采集、物资小站、生活庭院、手作工坊和滨水区域，以主路、庭院地面、开放式房间、工棚、码头和边界植物组织空间。已知对象使用固定分区坐标，其他对象按类别排列；六伙伴分散出生。工具的显示位置随携带者、存放对象或卡住对象改变，仅是显示映射，不写回模拟状态。

场景标签显示真实状态：耐久0为“坏了”，耐久不高于30为“待修理”，清洁度低于30为“脏了”，环境物产量0为“采空了”，食物新鲜度0为“变质了”，以及卡住、不可达、正层数Buff和占用者。30为预览提示阈值，不是新增游戏规则；没有该属性时不显示状态，恢复后自动消失，标记不会创建Buff。右上“场景状况”汇总异常和占用，可点击定位；展开全部对象可以找到被隐藏的普通标签。点击模型或标签在侧栏查看具体属性。

标签优先显示当前选择、观察伙伴和异常对象；普通标签碰撞时隐藏，缩放或悬停可查看。对象模型仍为程序化示意，装饰不可交互，路径尚不用于障碍寻路。地图左键平移、滚轮缩放保持不变。
