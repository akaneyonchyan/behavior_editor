# 使用方法

更新日期：2026-10-19。

## 导出行为图 PNG

顶部文件操作栏点击“导出 PNG”，默认“完整行为图 / 高清 2 倍”。可改为“当前可见区域 / 标准 1 倍”，再点击“下载 PNG”。文件名包含行为名称和本机日期时间。

完整图包含屏幕外节点、曲线伸出部分及边缘留白，不受当前平移缩放影响。当前可见区域按视口裁切，边缘节点可能不完整。图片保留深色背景、文字、自定义下划线、静态贝塞尔曲线和箭头；隐藏网格、流光、连接点、选择高亮和画布控件。关闭稍息后，图片与当前图一样隐藏第三轮和对应连线。

图片在浏览器本地生成，不上传图数据，不修改 JSON、选中状态、视口或撤销栈，也不将未保存行为标为已保存。图片下载位置由浏览器控制，不写入行为 JSON 文件。单边超过8192像素或总量超过2400万像素会提示降低清晰度或改导当前区域；不会静默缩小、裁掉完整图。

## 第一次绘制行为

1. 用桌面 Chrome/Edge 打开在线编辑器，选择本地保存目录。也可暂用浏览器草稿，但没有目录备份。
2. 首次没有缓存时生成空白模板：开始→判断→两个执行→循环→待机/结束，共7个节点、9条连线；循环准入不满足默认标记为跳出行为。配置字段留空，填写后即可使用。
3. 点击开始节点或画布空白处，在右侧填写名称、满足目标，以及需要的交互对象、消耗品、准入条件。
4. 从左侧拖入节点，落点对应松开鼠标的位置；从节点出口拖向另一个节点入口连接。点击节点在右侧填写内容。

编辑行为准入数据时，点击开始节点或画布空白处即可；顶部不再提供重复入口。
5. 判断先填写共享属性，再设置各分支；结果分别填写属性、Buff、产物及播放方式。下划线文字表示非标准候选，评审时需关注。
6. 点击保存，选定正式 JSON 文件。首次模板在此之前仅是缓存。

“新建”、首次初始化、找不到上次文件后的回退统一使用完整空白骨架（9节点、11条连线）。新建内容仅存缓存，手动保存后才创建正式文件。重开仍优先恢复已有草稿；只有开始节点的旧草稿不会被自动覆盖，可点击“新建”获取完整模板。

## 文件与恢复

可从文件管理器把一个 `.json` 行为图文件直接拖入画布，松开后打开并自动适配视野；是替换当前行为，不是合并节点。当前有未保存修改时会先确认，取消保留当前图，继续则归档原浏览器草稿。无效JSON、非行为图、文件夹或多个文件会提示错误，不替换原图。拖入节点仍保持原来的添加方式。

支持文件句柄的浏览器会记录拖入文件，保存时使用原文件并保留外部修改冲突检查；未提供句柄时仍能加载，但首次保存需要选择文件位置。读取期间如果又编辑了当前图，会保留新编辑并提示重新拖入，避免异步加载覆盖修改。

| 操作或数据 | 实际作用 |
|---|---|
| 保存 | 写回已打开或已保存的文件；首次调用弹出保存窗口 |
| 另存为 | 选择另一个正式文件 |
| 打开 | 读取本地 JSON；原生窗口默认定位已选目录，最终行为受浏览器权限影响 |
| 浏览器草稿 | 停止操作约0.5秒后写入，持续操作时每2秒补存；不同页面各自保存 |
| 本地自动缓存 | 有变化时约每15秒更新 .behavior-editor-cache/当前行为缓存.json；多个页面共享最近一次磁盘快照 |
| 空白模板 | .behavior-editor-cache/空白行为模板.json，供默认初始化使用 |
| 恢复草稿 | 展示其他浏览器草稿中最近20份，恢复后应另存为正式文件 |

浏览器后台节流、权限和系统休眠会影响定时执行，不能把15秒理解为绝对保证。缓存不会自动提交 Git。建议团队行为仓库忽略 .behavior-editor-cache/，只提交手动保存的行为文件。

下次进入会尝试恢复上次文件和草稿；未保存草稿优先。原文件找不到或损坏时回到空白模板，并保留可恢复的浏览器草稿。权限过期点击“恢复访问授权”。浏览器缓存与目录授权不跨设备、不跨浏览器配置文件；清理站点数据可能清除草稿与授权。

若原文件已被其他程序或页面修改，保存会提示冲突；先另存为，再比较合并。不要通过清空缓存绕过冲突保护。

旧版“行为恢复-随机编号.json”是历史备份，新版不会继续生成。确认内容已正式保存后再自行清理；更新版本前先保存工作，关闭旧标签页，重新打开网址。

## 公共库与常见问题

- 没有候选：打开公共库查看是否就绪，核对对象来源、条目启用状态和适用对象关联；可暂用自定义输入记录需求。
- 飞书刚改，页面没变化：页面每60秒检查发布数据；“刷新数据”只重新读取快照，不触发飞书同步。查看飞书同步时间，通常需5～10分钟，排队或失败可能更久。
- 只看到下载：当前环境可能不支持原生文件 API；用 Chrome/Edge 的 HTTPS 页面，或本机 localhost。
- 恢复文件未见于列表：列表读取浏览器草稿，不扫描磁盘；磁盘 JSON 可用“打开”读取。
- 显示“无未保存修改”但没有正式文件名：还只是缓存，首次使用仍需点击保存。


## 结束表演（2026-10-19修正）

结束只有一种节点、一个工具栏入口。每个实例配置一套表演和播放方式（单次／计次／计时），计次／计时可填写文字期望。结束节点用于行为内明确设计的收尾，不设结束类型字段。通用意外中断和监听跳出交给行为外规则，默认模板只有一个正常结束节点。

已有图的表演、名称、连线不变；旧 endReason 仅作为兼容数据保留，不展示、不参与规则，新建节点不生成该字段。旧 successAnimation/failAnimation 仍提供“拆分为两个结束节点”入口：按旧表演分配入线，保留原配置，支持撤销。拆分后的两个节点类型完全相同。正式文件仅手动保存后写回。

规则来源：[行为通用规则](https://xd.feishu.cn/wiki/HpD0wJZg7icrpKkXdkDcAjHDnBg)。结束类型不是编辑器规则，这是2026-10-19用户明确修正的产品约束。相关回归见 tests/endings.cjs、tests/endings.spec.cjs、tests/end-node.spec.cjs。

## 占用资源与行为结束（2026-10-19）

执行节点可声明“占用资源”（旧文件中的位移声明兼容保留）：对象来源＋属性名，支持公共库选择和自定义下划线输入。含义是该节点执行时产生、由本行为持有至结束的占用；仅移动或普通属性增减不能推断为占用。

结束节点的“释放资源（自动）”引用从开始可达且能通向本节点的前序声明，展示对象、属性、来源节点；修改、删除、断线、撤销及公共库改名均自动反映。各分支引用取并集，不意味着每次全部占用；设计语义是只释放本次实际产生、仍由本行为持有的资源。编辑器不模拟运行时，不凭对象类型猜测具体实例或释放顺序；同类型的不同占用由来源节点与声明ID分别追踪。

实现：occupiedResources=[{id,source,attribute}] 存在来源节点，utils/occupiedResources.js 按有效边遍历，排除禁用稍息路径、孤立节点和结束节点后的边。派生引用只在展示时计算，不复制写入结束节点。旧 releaseResources 原文放在核对区，需整理为前序声明；旧 targetCondition 仅兼容保留、不展示、不执行。

结束节点不再配置或展示目标判定。目标是否达成及后续调度属于行为之外的目标策略流程；开始节点中行为准入数据的满足目标、循环中的循环判定仍保留。回归见 occupied-resources.cjs 与 occupied-resources.spec.cjs。

判断分支的连续属性影响分别为“越高，概率越大”和“越低，概率越大”。旧版误写的“越低，概率越小”若已存入行为文件，会作为非标准文字保留并加下划线；请按实际意图重新选择，编辑器不自动反转旧规则含义。

## 按类型选择对象名

选择“对象来源”或“对象类型”后，在下方“对象名”中选择该类型的具体对象，也可手动填写；暂不指定时可留空。入口涵盖开始节点的目标/交互对象/消耗品/准入条件、判断属性、执行属性/Buff、循环条件及占用资源。

非公共库选项以下划线显示。切换类型不会清空已经填写的对象名，不属于新类型的名称会被标记；需要时再改选。判断节点选择的对象名自动传给各分支，结束节点自动引用前序占用对象。固定坐标仍按坐标填写。

公共内容库窗口新增“对象名录”，按“对象表”选择类型查询。目录初始为空，维护者在飞书填入对象并启用后，等待同步再刷新即可选择。


## 需求清单

点击顶部“需求清单”，按属性、对象、Buff、表演四页查阅当前行为中的待核对内容。清单覆盖全部节点（含未连接节点）和行为准入设置；相同内容按字段、原因和上下文合并，列出所有使用位置。点击位置关闭窗口并定位到对应节点，右侧打开编辑面板。支持搜索和导出完整 Markdown 清单，导出不受当前页签或搜索条件限制。

属性/Buff页包含未收录、已停用、对象不适用的引用以及自定义规则；对象页包含未匹配的来源、类型、具体对象、消耗要求和未结构化的产物。表演页汇总已填写的执行/结束表演以及自定义播放方式。当前没有表演资产库，表演一律标为“待核对资产”，不能据此断言资产缺失。

只读取当前图，不扫描本地其他行为文件，不修改原图或公共库。空白字段、普通节点说明/循环说明和已关闭稍息条件不计入。公共库尚未加载时暂停判断；缓存可用时标明快照时间，更新后重新汇总。未匹配只是需要核对或补充的线索，不等于游戏尚未实现。

PNG 默认保存位置：已设置本地存储目录时，点击“下载 PNG”会打开保存弹窗并默认定位到该目录，可修改文件名或另选位置。取消弹窗不生成或写入图片；未设置目录时自行选择。不支持 showSaveFilePicker 的浏览器使用普通下载，保存位置由浏览器下载设置决定。此操作不改变行为 JSON 的保存路径。

## 本地行为文件区

左侧节点列表下方显示所选本地保存目录中的行为 JSON 文件，可按文件名或行为名称搜索。点击文件切换查看和编辑，当前文件会高亮；有未保存修改时先确认，取消保留原图，确认后保留浏览器恢复草稿。切换后“保存”写回原文件，仍有外部修改冲突保护。

列表只读取目录当前层的 .json 文件，不进入 .behavior-editor-cache 或其他子目录。非法 JSON 禁止点击，悬停文件名可查看原因。新保存/另存为、切换目录以及返回浏览器窗口时自动刷新；Git 同步等外部改动也可以点“刷新文件”读取。列表只是磁盘内容索引，未保存编辑不会改写列表中的文件内容。每行仅展示文件名；刷新按钮位于目录名称右侧。

未设置目录时先点顶部“保存目录”；恢复的目录需授权时点“授权读取目录”。浏览器不支持目录访问时，继续使用顶部“打开”或拖入 JSON。默认空白缓存不会列成正式文件，需要手动保存到该目录后才会出现在文件区。


左侧节点入口采用双列三行紧凑排列，悬停可查看节点说明；快捷键说明默认折叠。下方文件区使用剩余高度，保持侧栏原宽度和画布大小。


## 配置拖拽排序（第一批）

准入条件、循环各步规则、判断属性和分支、执行节点属性/Buff/产物可从标题左侧“⠿”手柄上下排序。仅同一列表内移动，只有一条时手柄禁用。面板边缘自动滚动；松开确认，Esc或拖出列表取消。支持触摸手柄；键盘聚焦手柄后用空格抓取，上下方向键调整，再按空格确认。

每次完成排序只记录一次撤销，触发未保存状态与缓存，正式文件仍需手动保存。分支移动只改变展示位置，不改变原连线或概率；判断属性顺序同步各分支，每个属性自己的影响方式保留。执行属性、Buff分别组内排序，产物允许重复名称和空值。JSON、画布摘要及PNG沿用新顺序。排序不赋予条件优先级。

当前尚未接入：满足目标、交互对象、消耗品、占用资源列表。自动释放列表、循环三步顺序不属于可排序配置。


## 在线行为共享（2026-10-20）

左侧文件区新增本地／在线页签。在线从公开仓库 behaviors 目录读取，在主画布只读查看（非弹窗）；通过顶部“另存为”保存到本地目录后编辑。选择本地 JSON 上传时创建分支与 PR，审核合并后刷新目录查看。支持同名替换、版本冲突提示与本地覆盖保护。详见[在线文件说明](online-files.md)。本地自动缓存不上传。


## 跳出行为与旧位移迁移（2026-10-20）

判断分支、执行节点后续、循环各已启用出口，都可选择“连接节点”或“跳出行为”。后者显示节点色的“↗ 跳出行为”标记，可填可选说明，不配置外部流程，也不隐含结束表演、目标判定或资源释放。需要失败表演时，先连执行节点，再跳出。监听随时触发的通用中断无需逐节点配置。

切换为跳出会移除该出口的连线，保留原目标节点及其表演，支持撤销；切回连接节点时处于未连接状态。循环内部判断分支可独立配置跳出标记。在线只读预览、PNG、保存恢复及复制排序均保留标记。通用跳出的资源清理由行为外规则负责；正常结束仅展示可追溯的占用，无占用时隐藏。

新建不再提供位移节点，默认模板不含位移和中断结束。旧文件不自动改写：选中旧位移，点击“移除旧位移并接续”，仅在正常出口唯一且接续不会生成自身循环时执行，前序出口身份保持不变。原位移数据及涉及连线存入 behavior.legacyMovement，支持撤销；原结束节点不会自动删除。请核对原占用与自定义说明，外部占用不自动搬到执行节点。旧中断连线可逐条切换为跳出，不按节点名猜测。

缓存模板有独立版本；回退到旧缓存模板时采用新版内置模板。现有正式文件和编辑草稿继续恢复，不清空缓存，不批量迁移线上文件。examples/eat-snack.json 保留为旧格式兼容示例；新格式示例见 examples/external-exits.json。


## 在线需求汇总（2026-10-20）

切到“在线”页签后，顶部“需求清单”会读取全部已发布在线行为文件，无需先选文件，也不受左侧文件搜索过滤影响。按属性、对象、Buff、表演四个页签汇总；相同字段、内容、原因及对象上下文合并为一行，列出涉及文件及行为名称，可展开节点使用位置。不同对象上下文不强行合并。表演仍属于待核对资产，不代表已确认缺失。

点击清单内文件名，在主画布打开对应已读取版本，只读查看；本地草稿和撤销历史不被替换。“搜索需求清单”支持按行为文件名搜索。“导出完整清单”导出四个页签，包含文件来源、在线快照及公共库时间；不受当前搜索过滤影响。

打开窗口时读取在线目录，可点击“重新读取在线文件”更新；仅涵盖已发布版本，不含未合并 PR，存在发布延迟。读取失败逐文件提示，已成功读取部分仍可查看和导出，导出明确注明清单不完整及失败文件。全部读取失败、目录失败或公共库未就绪时不允许导出成功清单。关闭窗口取消剩余请求。公共库更新会重新核对本次已经读取的文件。

本地页签仍只汇总当前正在编辑的行为。在线扫描不需要 GitHub Token、不写仓库、不保存或修改本地行为。


## 循环容器与父子结构视图（2026-10-20）

循环使用可添加、删除和拖拽排序的结束条件列表。每轮执行前从上到下检查，满足任一条立即结束；全部不满足才执行内部节点。新建默认先判断目标条件，再判断最大次数。最大次数允许填写设计期望；每条目标条件可配置公共库属性规则，同一条内全部满足才成立，不填时引用行为准入数据中的满足目标。

循环容器顶部仅展示条件顺序和只读摘要；点击容器或标题后，统一在右侧调整类型、次数、排序和完整配置，包含添加属性规则与自定义下划线输入。在线为只读。容器内不重复绘制循环卡片。内部左侧的圆形开始图形连接本轮首个节点，执行顺序从左向右；判断分支上下排列，共同后续只展示一份。准入由内部判断节点表达，个性待机由内部待机节点表达。

外部前序连接容器左侧入口，循环结束从右侧出口连接后续节点。内部某分支提前离开时，经独立的分支出口连接容器外目标；不同分支的去向不会合并。嵌套循环逐层经过容器边界。折叠只隐藏内部流程，保留外部连线。内部左侧为开始标记，右侧为 ↻ 继续循环标记；明确连接到该标记才结束本轮并重新判定，无需画回左侧的长回线。

打开本地文件、恢复草稿、拖入文件和在线查阅都使用同一套循环规则。已有的准入／稍息设置自动成为内部判断／待机节点，保留属性、自定义文字和各分支去向，不需要点击转换按钮。正式文件仍仅在手动保存时写回；在线浏览不会替换本地编辑内容。

选中循环可在右侧“循环范围”选择本轮起点和内部节点、识别候选范围并确认。所有未连接出口保持未连接，确认范围或拖入节点均不自动补齐返回关系。外部连接到内部节点的操作会接到相应循环入口，避免从半途开始执行。

顶部页签依次为“连线视图／结构视图”，默认结构视图。结构视图支持普通节点与容器拖动、属性编辑、折叠和重排；复杂连线编辑可切换连线视图。完整 PNG 使用独立展开副本，包含条件、内部起点和边界连线，不改变当前折叠或保存状态。

### 拖动节点调整循环归属（2026-10-20）

空循环只移动自身，不锁定画布其他节点，也不会把静止节点自动收进来。拖动普通节点，在容器内部正文区域松开（以节点中心判定），即可加入该循环；从内部拖到外部则解除归属。折叠容器不接收拖入，开始节点始终在循环外。

从一个范围转移到另一个范围时，清除被移动节点与旧范围关联的入线、出线，以新归属为准，支持一次撤销／重做。目标容器为空时，该节点成为首个内部节点；原容器起点移走后自动选取剩余起点，无成员时恢复空容器。执行／待机末尾补齐新循环的内部返回关系，结构画布不显示回线；不会替原判断分支猜测新去向。

整体移动嵌套循环会携带它的内部节点与内部连线，只清理与外部的连线；不能把循环放进自己或自己的子循环。位置和父子关系随 JSON 与草稿保存，重排只调整位置，不改变成员关系。

结构视图中，点击连线任一显示线段即可选中整条连接，按 Delete 或 Backspace 删除；Shift 点击可多选。点击空白取消选择。删除连线保留节点布局，可撤销恢复；在线预览保持只读。

## 属性判断与影响规则（2026-10-20）

属性选择的三个字段统一显示为「对象大类／对象子类／判断项」，对应原 source／objectName／attribute，公共库引用和 ID 不变。Buff 输出仍显示 Buff 名，执行输出增减和准入条件保持各自含义。

分支属性影响拆成两个可自定义输入的选项：影响类型（数值高／数值低／具体值），影响规则（概率越高／概率越低／允许选中／排除选中／不影响）。非标准输入继续以下划线展示并纳入需求清单；只表达设计规则，不进行概率运算。具体值的比较内容尚无独立标准值字段，可通过自定义文字表达并列为需求。

文件中的 influenceType 和 influenceRule 为当前生效字段；influence 保留兼容描述，编辑时同步更新。读取历史文件时按明确的标准文字映射，未知描述原样留在影响规则，影响类型留空，不推断其含义。读取转换不直接覆盖磁盘文件。画布、在线只读、PNG 和需求清单均使用拆分后的字段。

循环右侧的 ↻ 标记不属于独立节点，不能删除或拖动，无单独配置。可从所属循环内的执行、待机、判断分支或嵌套循环的完成出口拖线到标记；普通新连线只允许返回直接所属循环。已有跨层返回沿容器边界展示，保持目标不变。连线可选中删除和撤销，折叠隐藏内部标记，PNG 展开副本保留。旧文件明确返回循环起点的线读取时改为返回循环判定；不生成缺失连线。
