# 共享行为文件

这里存放经审核合并的行为 JSON。编辑器左侧「在线」页签读取本目录的 main 版本，支持只读预览和下载到本地编辑。

上传通过独立分支和 PR 完成，不直接覆盖 main。所有文件与历史均公开，请只提交计划公开的行为。目录初始为空，不自动上传用户本地文件。

仅支持本层 `.json` 文件；不使用子目录，不放公共内容库快照。单文件上限 2 MB，文件名需可用于 Windows 本地保存。审核者应检查 `Validate shared behaviors` 和文件差异再合并。权限及使用方法见 [在线文件说明](../docs/tool/online-files.md)。
